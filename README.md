# Kobold

Монорепо онлайн-казино: своё казино, спортивная книга и маркет предсказаний.
Игры — свой код, работающий со своим WebSocket и своим леджером.

## Быстрый старт

```bash
pnpm install
cp .env.example .env
pnpm infra:up        # postgres + redis в docker
pnpm db:migrate
pnpm dev             # собирает пакеты и поднимает все приложения
```

- фронт — http://localhost:5173
- api — http://localhost:3000/api (health: `/api/health/ready`)
- admin-api — http://localhost:3002/admin (только localhost)

Отдельно: `pnpm dev:web`, `pnpm dev:api`.

## Структура

```
apps/
  web/           React 19 + Vite + TanStack Router/Query + Zustand, FSD
  api/           NestJS + Fastify: HTTP и WebSocket-гейтвей
  orchestrator/  воркер общих раундов, синглтон с leader election
  settler/       фоновый воркер: расчёт, сверка, отчёты
  admin-api/     операторские эндпоинты
packages/
  money/         BigInt в минорных единицах, округления, форматирование
  game-engine/   чистая математика игр + provably fair
  contracts/     zod-схемы и типы событий сокета
  db/            схема Kysely, миграции, кодек NUMERIC ↔ bigint
  ui/            дизайн-система: токены, компоненты, логотип, маскот
```

Дизайн-система собрана по макетам из `layouts/` — палитра, типографика,
геометрия, все состояния компонентов, знак и маскот Фикс. Витрина доступна
в дев-сборке на `/ui-kit`; подробности — в
[`docs/DESIGN-SYSTEM.md`](docs/DESIGN-SYSTEM.md).

`game-engine` общий между фронтом и бэкендом. Формула множителя существует
ровно один раз, и верификатор в браузере — вызов той же функции, которой
считал сервер.

## Команды

| Команда                                       | Что делает                          |
| --------------------------------------------- | ----------------------------------- |
| `pnpm dev`                                    | пакеты + все приложения             |
| `pnpm build`                                  | сборка всего                        |
| `pnpm typecheck`                              | типы по всему воркспейсу            |
| `pnpm test`                                   | тесты пакетов                       |
| `pnpm lint` / `pnpm lint:fix`                 | ESLint, включая правила слоёв FSD   |
| `pnpm format`                                 | Prettier                            |
| `pnpm db:migrate`                             | накатить миграции                   |
| `pnpm db:migrate:status`                      | что накачено                        |
| `pnpm db:reset`                               | пересоздать схему (только локально) |
| `pnpm infra:up` / `infra:down` / `infra:nuke` | postgres и redis                    |

Тяжёлые статистические тесты (10⁷ раундов Монте-Карло) гоняются отдельно:

```bash
pnpm --filter @kobold/game-engine test:slow
```

## Что уже работает

Фундамент собран и проверен на живой базе:

- регистрация, сессии (argon2, хэш токена в БД), кошелёк, леджер двойной записи;
- сиды, ротация с автоматическим раскрытием, атомарный nonce;
- Limbo и Dice целиком: идемпотентность, блокировка кошелька, лимиты,
  потолок прибыли, двойная запись, воспроизводимость раунда;
- верификатор в браузере, сходящийся с сервером байт в байт;
- leader election оркестратора с перехватом лидерства при падении;
- каркас WebSocket-гейтвея, очередей и дашборда банкролла.

Дальше по плану: `realtime` целиком, Crash поверх оркестратора, Mines и Towers,
`sports`, `markets`. Маршруты для них уже заведены — см. `docs/MAP.md`.

## Правила, которые стоит знать до первого коммита

**Деньги — только `bigint` в минорных единицах.** Ни `number`, ни `decimal.js`
как хранилище. Вся арифметика в `@kobold/money`, округление всегда указывается
явно и всегда в пользу дома.

**Математика игр — только в `@kobold/game-engine`.** `games/*` на бэкенде
содержат оркестрацию: транзакцию, лимиты, сохранение. Ничего больше.

**Денежная ручка обязана быть `@Idempotent()`.** Ключ приходит от клиента
и переживает ретраи.

**Порядок блокировок один на весь проект:** кошелёк, потом раунд или исход.

**На фронте зависимости идут только вниз по слоям FSD.** Проверяет линтер.

**Ничего не верстается мимо дизайн-системы.** Цвет, размер и радиус берутся
из токенов, компонент — из `@kobold/ui`. Новое состояние сначала появляется
в макете, потом в пакете, и только потом на экране.
